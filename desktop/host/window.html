SO ERREICHT MAN IHN

Beim ersten Aufruf warnt der Browser vor dem Zertifikat – es ist selbst erstellt. Unter „Erweitert“ → „Weiter zu …“ geht es weiter. Fragt Windows nach der Firewall: „Private Netzwerke“ erlauben, damit andere Geräte im Heimnetz hinkommen.

ZERTIFIKAT

–

Fingerabdruck (SHA-256). Zeigt der Browser beim Zertifikat denselben, bist du wirklich mit diesem Server verbunden und nicht mit einem anderen im Netz.

WINDOWS-APP VERBINDEN

Damit die Clavichat-App diesen Server nutzt: den Text als config.json in den Ordner der App legen und die App neu starten. Der Fingerabdruck sorgt dafür, dass sie genau diesem Zertifikat vertraut.
